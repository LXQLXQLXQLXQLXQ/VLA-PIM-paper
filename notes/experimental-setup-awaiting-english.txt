Previous English draft, retained only for reference (not source-approved):
We calibrate a VLM memory-access model with measurements on NVIDIA Thor and simulate the PIM cycle-accurately in Ramulator2~\cite{ramulator2}. On the GPU side, we run $\pi_{0.5}$~\cite{pi05} on Thor with the PyTorch implementation of OpenPI~\cite{openpi} (MHA8 configuration, BF16, batch size~1, action chunk length $H=16$, 10 denoising steps, 3 camera views plus 200 text tokens). From these runs we obtain the duration and the bytes read and written of each VLM kernel, as well as the durations of the nonlinear operators of the AE. On the PIM side, we build a cycle-accurate simulator on Ramulator2 that models the VLM memory accesses and the PIM commands in the same memory controller. DRAM timing follows the LPDDR5X-8533 speed bin of JEDEC JESD209-5C~\cite{jedec_lpddr5}. Table~\ref{tab:sim-params} lists the main simulation parameters.
