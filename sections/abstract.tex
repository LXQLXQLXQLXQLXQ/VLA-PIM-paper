Vision-Language-Action (VLA) models are a core paradigm for embodied AI, but meeting strict real-time inference on resource-limited edge platforms remains challenging. A typical VLA model cascades a relatively compute-intensive Vision-Language Model (VLM) and a memory-bound Action Expert (AE), motivating heterogeneous hardware. In this work, we propose \emph{ActPIM}, a heterogeneous GPU-LPDDR5X-PIM system for edge VLA inference through architecture-dataflow co-design. ActPIM uses rank-level partitioning to execute the VLM on GPU while concurrently offloading AE to LPDDR-PIM. However, shared-bus contention limits GPU-PIM concurrency, as PIM execution leaves fragmented bus idle windows and incurs frequent inter-rank and KV cache transfer. To resolve this, we design an input-preloading microarchitecture and dataflow, while optimizing the operator-aware data layout and KV cache management, increasing bus availability to the GPU from 10\% to 90\%. Ramulator-based cycle-accurate simulations demonstrate 1.4\texttimes{}/1.3\texttimes{} speedups and 1.3\texttimes{}/1.2\texttimes{} higher energy efficiency over the GPU baseline and AttAcc PIM.
