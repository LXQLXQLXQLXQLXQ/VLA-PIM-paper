Vision-language-action (VLA) models require low-latency inference on edge platforms with tight compute, power, and memory bandwidth budgets. Concurrent execution of the vision-language model (VLM) and action expert (AE) can improve inference throughput, but shared memory bandwidth limits the gains on a single GPU. The AE’s low operational intensity favors processing-in-memory (PIM), which can accelerate its computation while reducing bandwidth competition with the VLM. We present VLA-PIM, a GPU–LPDDR5X-PIM system that uses rank-level partitioning to overlap VLM execution on the GPU with AE linear computation in PIM. However, fragmented bus idle windows and intermediate data transfers hinder efficient overlap. We co-design an input-preloading microarchitecture and communication-efficient dataflows to create contiguous GPU access windows and reduce external transfers. Evaluation using NVIDIA Thor measurements and cycle-accurate simulation shows a 1.76\(\times\) speedup over a dual-stream GPU baseline while preserving 92.1\% of standalone VLM bandwidth during PIM execution.
